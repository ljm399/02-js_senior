## 1.5 封装Cache(缓存)(里面有上面的方法)

#### 创建一个具有储存对象的Storage类

- 因为单靠Storage储存和获取对象值太麻烦
  - JSON.parse(localStorage.getItem('name'))
  - JSON.stringify({..})

```
class Cache {
  setCache(key, value) {
    if(!value) {
      throw new Error('value is required,value必须有值');
    }

    if(value) {
      this.storage.setItem(key, JSON.stringify(value))
    }
  }

  getCache(key) {
    const result = this.storage.getItem(key);
    if(result) {
      return JSON.parse(result);
    }
  }

  removeCache(key) {
    this.storage.removeItem(key);
  }

  clear() {
    this.storage.clear();
  }

  //目的:判断用户是sessionStorage还是localStorage
  constructor(isLocal = true) {
    this.storage = isLocal ? localStorage : sessionStorage;
  }
}
```

## 2.3 正则规则

### 字符类

- \d (digital) [0-9]
- \s (space) 如空格,\t ,换行符\n以及其他稀有字符如\v,\f,\r
- \w [0-9a-zA-Z_] 注意有下划线
- . 匹配除\n换行符以外的所有字符
- 反向
  - \D 除\d以外的其他
  - \S 除\s 
  - \W 除\w

### 锚点

- ^匹配文本开头
- $结尾

### 词边界

- /b: 判断所在位置的一侧是否是/w,另一侧是否非/w

- ' abc '.match(/\babc\b/),有两个/b,则一个匹配失败则返回null

### 转移字符串

- \
- 需要转义的有 [] \ $ | * + ( )

### 范围

[1-9] 

[abc]

### 排除

[^1-9]非1-9

### 量词

+ 加号 :{1,}
+ ? {0,1}
+ * {0,}
  

### 大括号

- a{1,}等于量词的+

### 贪婪和惰性模式

- 启动:+? , ? 或者??

```
  const message = "24岁<大专生>,面试为什么要你 因为我有<技术>,<我是什么人我平时干什么决定>"
    // 默认: 贪婪模式
    const reg = /<.+>/ig
    console.log(message.match(reg))//<大专生>,面试为什么要你 因为我有<技术>,<我是什么人我平时干什么决定>
    

    // 惰性模式
    const reg2 = /<.+?>/ig
    console.log(message.match(reg2))
```

- 贪婪直接匹配到最后一个的> 即干什么决定>,而不是大专生>



### or和整体

- (abc|cba)

- /(abc|cba|nba){1,}/ig
