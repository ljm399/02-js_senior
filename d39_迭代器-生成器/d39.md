## 一,迭代器Iterator

### 2.1 什么是迭代器,创建迭代器

```
const nums = [100, 200, 300]
    function createArrayIterator(arr) {
      let index = 0;
      return {
        next: function() {
          if(index < arr.length) {
            return { done: false, value: arr[index++]}
          } else {
            return { done: true }
          }
        }
      }
    }
```

- 帮助我们对某个数据结构遍历的对象,其他语言如java都有迭代器(索引的光标),只不过实现不同
- js中迭代器的标志:有个特定的next方法
- 实现next方法
  - {done: false/true, value: value/undefined}
  - done
    - 如果可以产生下一个值,则false
    - 迭代完了,就true
  - value
    - done为true时可省略



### 2.2 什么是可迭代对象

- 实现:迭代器在对象外和对象内

- 一个对象实现Symbol.Iterator协议,则是一个可迭代对象
  - 这个对象必须实现@@Iterator方法

- 好处
  - 可以进行迭代操作
    - 如for..of


```
    const infos = {
      name: "John",
      age: 30,
      city: "New York",
      friends : ["Alice", "Bob","bulb"],
      [Symbol.iterator]: function() {
        let index = 0;
        // this绑定:const iterator = infos[Symbol.iterator]();知道是infos
        
        // const keys = Object.keys(this);
        // const values = Object.values(this);
        const entries = Object.entries(this);
        const infosIterator = {
          next: function() {
            if(index < entries.length) {
              return { value: entries[index++], done: false };
            } else {
              return { done: true };
            }
         }
        }
        return infosIterator;
      }

    }
    
    for(let info of infos) {
      console.log(info); 
      /* 
      (2) ['name', 'John']
      (2) ['age', 30]
      (2) ['city', 'New York']
      (2) ['friends', Array(3)]
      */
    }
```

### 2.6 迭代器的中断执行(了解)

- break,return,throw都可以,但推荐是return,而且是可迭起里面的return方法

- ```
  [Symbol.iterator]() {
          let index = 0;
          const iterator = {
            next: () => {//必须用箭头函数，否则this指向不对
              if (index < this.friend.length) {
                return { value: this.friend[index++], done: false };
              } else {
                return { done: true };
              }
            },
            return: () => {
              console.log('迭代器中断执行了')
              return { done: true };
            }
          }
          return iterator;
        }
  ```



## 二. 生成器Generator

- 控制函数什么时候执行,暂停和结束

### 3.1 生成器函数和生成器对象

- 生成器函数:
  - function *
  - 返回生成器对象
  - 内部可以通过yield控制函数的执行
  
- 生成器是个特殊的迭代器





### 3.2 生成器的返回值和参数

```

### 3.4 生成器代替迭代器

- 要是控制台是[obj,obj],再点击一次刷新就有里面的值

  

- ```
      const name = ['John', 'Jane', 'Doe']
      function* createArrayIterator(arr) {
        for (let i = 0; i < arr.length; i++) {
          yield arr[i]
        }
      }
  ```

- 语法糖

  - ```
     function* createArrayIterator(arr) {
          yield* arr
        }
    ```

  - ```
       // yield* 语法糖替代之前可迭代类的写法
        class Person {
          constructor(name, age, height, friend) {
            this.name = name;
            this.age = age;
            this.height = height;
            this.friend = friend;
          }
          
          //实例方法:即函数,不用加function
          *[Symbol.iterator]() {//加*表示这是一个生成器函数，Symbol.iterator()是可迭代类的标志
            yield* this.friend
          }
        }
    ```
